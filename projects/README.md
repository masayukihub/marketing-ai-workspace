# Projects

每个目录是项目工作入口。`project.yaml` 是统一的导航、当前 Gate、Blocker 与 Next Action Manifest；README 保留人类可读入口。Product Truth、Project Memory、Decision、Claim、Visual Freeze 和资产仍由 Manifest 指向其原始负责人，不在这里复制。

项目任务先运行 `skills/project-context-resolver/scripts/resolve_project_context.py`，再让执行 Skill 消费最小 Context Package。
