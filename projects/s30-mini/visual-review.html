07 · Approval Boundary

Architecture Approval ≠ Pattern Approval

Architecture Approval

确认 Visual DNA、渠道职责、Recipe 角色顺序与 Existing Runtime 接口合理；不批准任何具体 Pattern、文案、Claim、图片或 Template 选择。

Pattern Approval

对 Candidate Pattern / Recipe 的结构适用性进行具名人工批准。即使通过，Product Truth、Claim、Asset、Hardening、Mobile QA 与 ESP Gate 仍保持独立。
