## USE

- 技术证明之后用人物场景展示使用结果
- 将音质、降噪、连接等技术群分章
- 把电池等购买指标单独展示
- 用无文字场景面控制节奏

## ADAPT

- SwitchBot页面减少受赏依赖，把信任建立在产品机制与官方证据上
- 暗色只用于重点技术章节，不形成全页黑色
- 程序化生成技术标签和日文，不把文字烘焙进场景

## AVOID

- 复制EarFun黑色渐变、技术Logo墙或受赏墙
- 用一张Hero同时塞奖项、规格、功能和口号
- 在没有授权与来源时使用第三方Logo
- 直接复制竞品技术图、UI、文案或完整布局

## Good For

- 技术与性价比并重的消费电子
- 需要在机制说明和生活场景之间切换的页面
- 多项连接与音频标准需要分章解释的产品
