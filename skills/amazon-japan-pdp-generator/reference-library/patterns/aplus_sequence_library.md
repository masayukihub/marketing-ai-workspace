# A+ Sequence Library

> A+ continues the decision story after Gallery; it should not replay the same seven images in a longer format.

## APLUS-CATEGORY-WORKFLOW

- Best for: AI hardware / new category / workflow product
- Reference ASINs: B0FQ5J7HFQ
- Sequence: Category Hero → Problem and Job → Input or Setup → Transformation Mechanism → Output or Benefit → Two Real Scenarios → Trust and Conditions → Comparison or FAQ
- Logic / Rhythm: Light educational chapters alternate with product and real scenarios; only one high-density workflow module appears at a time.

## APLUS-PERFORMANCE-SYSTEM

- Best for: robotics / cleaning appliance / multi-part system
- Reference ASINs: B0F66LKTV6, B0FX81HWQ3
- Sequence: System Hero → Core Mechanism → Performance Proof → Environment Adaptation → Maintenance Automation → Control or Ecosystem → Model Comparison → FAQ or Conditions
- Logic / Rhythm: Mechanism and scenario alternate; avoid four consecutive dense navigation carousels.

## APLUS-AUDIENCE-RELIEF

- Best for: family / pet / wellness / specific household problem
- Reference ASINs: B08131HFSG
- Sequence: Audience Hero → Problem Education → Mechanism Proof → Relief Scenario → Daily Fit → Quiet or Safety Detail → Desired-life Closure → Comparison or FAQ
- Logic / Rhythm: Mostly light and warm, with one darker or quieter lifestyle interval to prevent monotony.

## APLUS-TECHNOLOGY-PROOF

- Best for: premium electronics / invisible technology / enthusiast comparison
- Reference ASINs: B0GK1QFGF6, B0FWQY84L6
- Sequence: Value Hero → Technology Concept → Primary Mechanism → Measured or Observable Proof → Human-use Scene → Everyday Utility → Comparison → FAQ
- Logic / Rhythm: Do not place more than two dense technical modules consecutively; use a human scene or light field as a reset.

## APLUS-JAPAN-FIT-CONFIDENCE

- Best for: installation-sensitive smart home / high-consideration device
- Reference ASINs: B0FX81HWQ3, B08131HFSG
- Sequence: Japan-use Hero → Core Benefit → Mechanism Proof → Real Home Scenario → Installation and Size → Compatibility or Ecosystem → Support and Privacy → FAQ
- Logic / Rhythm: Start human and local, place technical proof in the middle, then end with explicit fit and ownership conditions.
