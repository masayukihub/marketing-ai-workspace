# Gallery Sequence Library

> Gallery sequences are seven decision jobs, not seven feature slots. The first image remains the Amazon-compliant official main image.

## GALLERY-FAMILIAR-TECH

- Best for: familiar consumer electronics / feature-comparison categories
- Reference ASINs: B0GK1QFGF6, B0FWQY84L6
- Sequence: Official Main → Value Hero → Primary Mechanism → Performance Proof → Real Scenario → Everyday Fit → Comparison or Purchase Confidence
- Logic / Rhythm: Confirm the product, justify the value quickly, explain one decisive mechanism, prove it, then move into lived use and selection.

## GALLERY-NEW-CATEGORY

- Best for: AI hardware / new workflows / low category familiarity
- Reference ASINs: B0FQ5J7HFQ, B08131HFSG
- Sequence: Official Main → Problem or Audience Hero → What It Does → Input or Setup → Transformation or Mechanism → Tangible Outcome in Scenario → Fit and Conditions
- Logic / Rhythm: Teach the job before listing capability. Keep the physical product visible between workflow and software outcomes.

## GALLERY-MECHANISM-PERFORMANCE

- Best for: robotics / cleaning appliances / performance-led systems
- Reference ASINs: B0F66LKTV6, B0FX81HWQ3
- Sequence: Official Main → Performance Hero → Core Mechanism → Failure-point Proof → Environment Fit → Ownership Effort → Confidence or Comparison
- Logic / Rhythm: Move from result to mechanism, then test the mechanism against the shopper's likely failure points before addressing ownership.

## GALLERY-AUDIENCE-PROBLEM

- Best for: audience-specific home products / wellness or family use
- Reference ASINs: B08131HFSG
- Sequence: Official Main → Audience Problem → Core Proof → Relief Scenario → Daily Safety or Fit → Mechanism Detail → Desired-life Closure
- Logic / Rhythm: Keep the target person or household visible. Proof reassures, while the last image returns to the life they want.

## GALLERY-JAPAN-FIT-CONFIDENCE

- Best for: large smart-home devices / installation-sensitive products / high-consideration appliances
- Reference ASINs: B0FX81HWQ3
- Sequence: Official Main → Japan Fit Hero → Core Value → Mechanism Proof → Real Home Scenario → Installation or Ecosystem Fit → Support and Purchase Confidence
- Logic / Rhythm: Resolve space, placement or household fit early, then prove value and close with conditions, support and compatibility.
