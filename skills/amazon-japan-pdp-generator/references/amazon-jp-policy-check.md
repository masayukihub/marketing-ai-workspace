# Amazon Japan Policy Check

Amazon 规则会变化。不要把本文件中的示例名称、数量或尺寸视为当前最终规则。

## 每次必须核对

1. 商品类目对应的 Main Image 与 Additional Image 要求。
2. 当前 Title 字符、禁止词和类目 Style Guide。
3. Bullet 数量、字符与 HTML/特殊字符限制。
4. Standard / Premium A+ 资格、最大 Module 数量、可用 Module 类型、图片尺寸、移动端裁切和 Alt Text。
5. Comparison Chart 允许字段与跳转行为。
6. Rating、价格、促销、保障与外部链接的可展示范围。

## 来源优先级

1. 当前 Seller Central Help / A+ Content Manager / 类目 Style Guide。
2. Amazon 官方 Seller University 或 News_Amazon 公告。
3. Amazon 官方公开页面。
4. Seller Forum 用户回复只能作为线索，不作为最终规则。

记录：URL、页面标题、访问日期、市场、账号/品牌资格、确认结果和限制。无法进入 Seller Central Builder 时使用 `Module Availability: Need Verification`。

## 稳定的保守基线

- Main Image 准确展示销售商品，白底，不放营销文字、Logo、边框、水印或未包含配件。
- Main Image 与 Additional Images 中的产品本体必须来自用户提供的官方产品素材。主图需重新完成裁切、尺寸、留白、居中、锐度和占比处理；不能把源图原封不动复制为成品。
- 正式素材禁止用 AI 生成、重画、补画或替换产品本体。AI 只可用于场景、人物、背景、灯光、道具和构图扩展，然后合成官方产品抠图或 Render。
- Additional Images 可承担使用场景、功能、证明、尺寸、内容物与适用范围，但每张保持一个主 Message。
- A+ 应使用多种适合的 Module 组合，并考虑移动端重排；内容单元不等于独立横 Banner，也不设置“至少15张”目标。
- 只有获得相应品牌与 A+ 资格后，Module 计划才可标记 `Confirmed`。

若当前官方规则与本 Skill 冲突，始终以当前 Amazon Japan 官方规则为准，并更新本次来源记录；不要静默改写历史产物。
