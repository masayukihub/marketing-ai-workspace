# Amazon Creative Page System Upgrade

This upgrade changes the internal creative method, not the production runtime.

## Added capabilities

1. Page-level consumer decision story instead of feature-count-driven planning.
2. `Why This Product Exists` tension / trade-off framing.
3. Dedicated Brand Story contract.
4. Internal competitor research separated from publishable same-brand Series Comparison.
5. Decision-oriented comparison hierarchy.
6. Copy ↔ Visual Fidelity hard gate.
7. Mobile semantic-proof QA.
8. Expanded A+/EBC handoff for Brand, Comparison and Native Copy.

## Unchanged boundaries

- `jp-commerce-content-flow` remains the only full production entry.
- Product Truth and Approved Claims are unchanged.
- Existing S30 Visual Freeze and rendered assets are unchanged.
- Amazon Renderer / delivery runtime is unchanged.
- Reference pages inform structure only; no layout, text, image or trade dress is copied.
