# Mobile Fidelity Checklist

Mobile QA must verify semantic proof, not only text readability.

For every critical unit check:

- H1 remains readable at target mobile width.
- Main product / proof object remains visually dominant.
- Scale cues do not disappear after cropping.
- Mechanism detail remains visible or has a mobile-specific crop.
- Comparison remains usable through responsive stacking or verified scrolling.
- Native copy is not duplicated inside raster text.
- Brand Story still reads as brand-level content rather than a generic product tile.
- No new claim is introduced by a mobile-only crop, badge or graphic.
- Carousel mobile strategy covers every slide, not only the first slide.

A desktop PASS does not automatically imply mobile PASS.
