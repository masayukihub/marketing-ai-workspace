# Page Creative QA Summary Contract

Whole-set review should end with one compact summary:

```markdown
## Page Creative QA

- Page Story: PASS / REVISE / BLOCKED
- Brand Story: PASS / REVISE / NOT_IN_SCOPE
- Series Comparison: PASS / REVISE / INTERNAL_ONLY / NOT_IN_SCOPE
- Copy ↔ Visual Fidelity: PASS / WEAK / FAIL
- Mobile Proof: PASS / REVISE / NOT_TESTED
- Product Accuracy: PASS / BLOCKED
- Claim / Evidence: PASS / PENDING / BLOCKED
- Delivery Completeness: COMPLETE / PARTIAL / BLOCKED
```

Any `FAIL` in Copy ↔ Visual Fidelity, Product Accuracy or unsupported Claim blocks whole-set approval even if other scores are high.
