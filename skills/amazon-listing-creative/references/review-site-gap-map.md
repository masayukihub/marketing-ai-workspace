# Review Site Gap Map

本文件记录本次 Skill 优化针对的结构性缺口，不复制具体页面视觉、Trade Dress、图片或未验证产品事实。

## 目标缺口

### 1. Whole-page Framework

旧创意流程偏单张图片与 Gallery 角色，容易形成 Feature 堆叠。

改进：

- `Why This Product Exists`
- `Consumer Decision Questions`
- `Page Story Spine`
- Gallery / A+ / Brand Story / Series Comparison / FAQ 分工

### 2. Brand Introduction

旧流程容易把 Brand 作为 Listing 最后一张或泛化口号。

改进：

- Brand Promise
- Product Philosophy
- Why This Product Fits Brand
- Ecosystem / Trust

明确品牌层与产品层边界。

### 3. Comparison

旧流程容易把竞品研究与正式 Comparison Table 混用，或只做规格表。

改进：

- Internal Competitor Matrix = INTERNAL_ONLY
- Publishable Series Comparison = 同品牌选型
- Recommended For / Home Fit / Key Differentiator 优先于裸参数

### 4. Copy vs Render

旧 Brief 中 Copy、Evidence、Visual Concept 并列存在，但没有硬性语义一致性 Gate。

改进：

- Visual Proof
- Proof Visible Without Copy
- Visual Introduces New Claim
- Mobile Proof Visibility
- `PASS / WEAK / FAIL`
